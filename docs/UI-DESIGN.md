# Branchlet · UI 设计与交互规范

本文记录当前实现，作为后续页面和组件维护的依据。产品定位为中文、本地运行的 Git 图形工作台，使用清晰的分区、浅色底面和绿色操作强调，帮助用户确认「在哪个仓库、哪个分支、将执行什么操作」。

## 视觉系统

核心颜色由 `src/styles.css` 的 CSS 变量管理，深色主题通过根节点 `data-theme="dark"` 切换。

| Token          | 浅色      | 深色      | 用途                     |
| -------------- | --------- | --------- | ------------------------ |
| `--bg`         | `#f8fafb` | `#151e22` | 页面底色                 |
| `--surface`    | `#ffffff` | `#1c282e` | 卡片、工具栏、主要面板   |
| `--sidebar`    | `#f6f8f9` | `#172227` | 左侧导航                 |
| `--text`       | `#293746` | `#d2dfe2` | 主要文字                 |
| `--muted`      | `#8c97a4` | `#81979d` | 辅助信息                 |
| `--border`     | `#e8ecef` | `#2b3a40` | 分隔线与面板边框         |
| `--green`      | `#16866b` | `#299f7e` | 主要按钮、品牌、操作强调 |
| `--green-soft` | `#eaf5f0` | `#213b32` | 绿色辅助底面             |
| `--hover`      | `#f4f7f8` | `#26383e` | 悬停反馈                 |
| `--input`      | `#ffffff` | `#18252b` | 输入底面                 |

- 字体优先序包含 DM Sans、Noto Sans SC 和系统字体；中文回退到 Microsoft YaHei 等本机字体，不依赖在线字体请求。
- 根字号 13 px；页面标题通常 25 px，宽屏升为 28 px；面板标题通常 12–14 px，路径、时间、徽标采用更小的辅助字号。
- 路径、哈希与快捷键使用 Cascadia Code / SFMono-Regular / Consolas 等等宽字体；长路径省略显示，并通过悬停标题或复制按钮访问完整内容。
- 常用面板圆角 8–9 px，按钮 6–7 px，模态窗口 16 px；边框承担主要层次，阴影保持轻量。
- Lucide 线性图标与文字共同表达操作；绿色表示主要操作或正常状态，琥珀色表示待处理，红色用于删除和错误，紫 / 蓝色用于分类辅助。

## 工作台布局与十个页面

桌面布局由 224 px 固定侧栏、72 px 顶栏、主体和 28 px 底部状态栏组成。主内容最大宽度为 1750 px，常规横向留白为 34 px。侧栏提供九个工作页面、仓库列表、设置和帮助；顶栏提供仓库面包屑、搜索、主题与操作记录。

每页保留标题区及仓库工具栏，持续显示真实仓库路径、当前分支、获取 / 拉取 / 推送入口。当前导航通过绿色底面、文字与左侧标记强调；示例仓库带独立标识。

| 页面            | 布局与主要交互                                                                                                      |
| --------------- | ------------------------------------------------------------------------------------------------------------------- |
| 仓库概览        | 四项指标卡；近期提交图与工作区预览并排；下方本地分支卡片。指标和预览可跳转到对应功能页。                            |
| 仓库文件        | 独立页面，顶部「默认列表 / 树状结构」切换与目录面包屑；左侧文件与文件夹导航，右侧只读文本预览，显示文件大小和状态。 |
| 工作区更改      | 左侧未暂存 / 已暂存列表与提交表单，右侧 Diff；点击文件选中并读取对应版本；暂存、取消暂存与丢弃入口贴近文件。        |
| 提交历史        | 可搜索的时间线图谱；选中提交后展示作者、时间、哈希、正文和 Diff，提供拣选 / 撤销操作。                              |
| 分支管理        | 全部 / 本地 / 远程分段筛选；表格包含名称、最近提交、同步状态和操作；当前分支单独标识。                              |
| 储藏区          | 卡片展示说明、引用和时间；应用 / 弹出并列，删除使用危险操作确认。                                                   |
| 标签            | 卡片展示版本名、说明和哈希；可查看目标提交、创建轻量 / 附注标签、推送标签或删除本地标签。                           |
| 远程仓库        | 远程配置卡片展示获取和推送地址；地址可复制；提供获取、推送、添加与移除配置。                                        |
| GitHub Releases | 显示远程目标与连接状态；令牌连接、版本卡片、草稿 / 预发布标签、附件选择与上传；发布草稿使用最终确认。               |
| 设置            | 作者身份与外观偏好分区；姓名 / 邮箱明确标记仅用于当前仓库；主题即时切换，底部显示产品信息。                         |

## 提交图谱与差异阅读

- `CommitGraph` 使用真实提交的 `parents` 计算连接，不根据列表位置虚构父子关系。每行 66 px，轨道间距 19 px，图谱左内边距 24 px。
- 轨道色依次为 `#16866b`、`#8b6dd7`、`#548ac7`、`#d99442`、`#cb728f`、`#52a5a0`；颜色用于区分可视轨道，不固定映射某个分支名称。
- 当前选中节点使用实心与淡色外环；合并节点稍大。未加载或被筛除的父提交显示短虚线延续；概览仅展示前 7 条，历史使用已加载记录。
- 提交行展示说明、引用标签、作者、相对时间与短哈希；操作依赖实际选中的提交。图谱附有可读取的行标签，装饰 SVG 不重复朗读。
- `DiffViewer` 使用统一视图，依次展示旧行号、新行号、`+` / `−` 标记与代码；头部汇总当前显示补丁的新增 / 删除行数。
- 新增行浅底 `#effaf2`、文字 `#327c58`；删除行浅底 `#fff0ef`、文字 `#a96062`；区块标题底色 `#f1f6fc`。符号和行号使差异不只依赖颜色表达。
- 长代码在 Diff 内横向滚动；深色主题覆盖代码底面、增删行与图谱节点填充。界面不提供文件编辑、按行暂存或图片差异查看器。

## 弹窗、表单与焦点

仓库弹窗采用 540 px 宽度、可滚动内容和固定顺序的标题 / 内容 / 操作区。顶部「打开仓库 / 新建仓库 / 克隆仓库」标签页共用路径输入，克隆增加 URL；本地目录浏览器可展开、进入子目录、返回上一级并选择当前文件夹。

通用操作弹窗支持单行、多行、默认值与必填字段，底部右对齐取消与确认按钮。危险确认采用红色主按钮，描述明确目标和结果；无输入的危险操作默认聚焦「取消」。

弹窗使用 `role="dialog"`、标题关联和模态语义；打开后聚焦首个输入，循环限制 Tab 焦点，关闭后恢复触发控件焦点。空闲时可按 Esc、点击关闭或遮罩退出；提交期间禁用关闭和重复提交。表单错误留在弹窗内，不清空已输入内容。

Releases 的令牌输入与提交作者设置分开；创建表单默认保存草稿，附件选择与上传分步操作。仓库文件的列表与树共用同一预览区，文件内容按只读显示，符号链接不跟随读取。

## 状态与反馈

| 状态              | 表达与后续操作                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------- |
| 加载 / 执行中     | 页面及 Diff 读取提示、旋转图标、顶部进度条和底栏操作名；相应操作按钮禁用。                         |
| 成功              | 短暂结果提示，并加入当前会话操作记录；重新读取仓库状态更新列表和统计。                             |
| 错误              | 红 / 琥珀提示与具体 Git 错误；仓库读取错误保留重试入口，表单错误就地显示。                         |
| 空列表 / 未选择   | 图标、简短说明与适用的下一步按钮；Diff 区提示选择文件，空历史提示先创建提交。                      |
| 冲突 / 操作进行中 | 工作区显示冲突数量；状态横幅提供查看工作区、中止确认、解决并暂存后继续。文件内容在外部编辑器处理。 |

## 响应式与主题

| 条件           | 当前布局调整                                                                                     |
| -------------- | ------------------------------------------------------------------------------------------------ |
| 宽度 ≥ 1500 px | 增大标题与指标数字、卡片留白；概览图谱占更大比例。                                               |
| 宽度 ≤ 1220 px | 侧栏缩为 202 px，主体留白 24 px；历史详情与设置转为单列，收紧表格。                              |
| 宽度 ≤ 1000 px | 侧栏缩为 190 px；指标变两列，概览隐藏重复工作区预览；工作区上下排列，文件分组仍可并排。          |
| 宽度 ≤ 760 px  | 侧栏变为带遮罩的抽屉；顶栏高 60 px，搜索变图标；主体占满宽度，文件区单列，操作条与卡片内容重排。 |
| 宽度 ≤ 600 px  | 弹窗外边距缩为 14 px、内容内边距 20 px，窗口按视口限高滚动。                                     |
| 高度 ≤ 920 px  | 收紧侧栏垂直间距、隐藏说明卡片；侧栏允许滚动，底部设置和帮助可达。                               |

最小页面宽度为 360 px。浅 / 深色主题由顶栏或设置切换并写入本地存储；深色覆盖主面板、图谱、Diff、弹窗及错误状态。系统启用减少动态效果时，收缩动画和过渡时间。

## 键盘操作与维护

| 快捷键               | 作用                                                  |
| -------------------- | ----------------------------------------------------- |
| Ctrl / ⌘ + K         | 打开 / 关闭搜索，检索已加载提交、本地分支和页面操作。 |
| Ctrl / ⌘ + R         | 刷新仓库数据。                                        |
| Ctrl / ⌘ + Enter     | 在提交说明框中提交已暂存更改。                        |
| Esc、Tab / Shift+Tab | 关闭空闲浮层、按可视顺序移动焦点。                    |
| ↑ / ↓、Home / End    | 在图谱行之间选择提交。                                |
| ← / →、Home / End    | 在仓库弹窗的三个标签页之间切换。                      |

页面样式维护于 `src/styles.css`；可视化组件与专属样式位于 `src/components/GitVisuals.tsx` / `git-visuals.css`；弹窗位于 `Dialogs.tsx` / `dialogs.css`。新增交互应沿用现有按钮、反馈与确认模式，并同时检查浅色、深色、窄屏和键盘焦点状态。
